# 异步主动SLAM架构：高频FastSLAM 2.0 + 低频决策触发

## 1. 核心问题与解决思路

你的核心诉求是：**FastSLAM 2.0 后端需要高频实时运行以保证定位连续性，但主动决策不应每一步都执行**，否则会导致目标频繁切换、路径抖动、计算资源浪费。解决思路是构建**双循环异步架构**：

**高频循环（FastSLAM 2.0 后端）**：以传感器频率（如10-50 Hz）持续运行，每个时间步接收里程计增量和观测数据，实时更新粒子集合、位姿估计和地图。这个循环**不**做决策，只负责状态估计，确保机器人始终知道"我在哪里"。

**低频决策循环（主动规划器）**：只在**触发条件满足时**才执行，评估当前态势、计算信息增益、选择下一个目标点或控制指令。这个循环**不**做状态估计，只负责决定"去哪里"。

两层之间通过一个**共享的信念状态（belief state）**和**状态机（state machine）**进行协调：高频循环持续更新信念，低频循环读取信念并在合适时机做出决策。参考 MDR-SLAM [^44^] 的完全解耦设计，其位姿估计节点（~20 Hz）与地图融合节点（4.7 Hz）通过消息异步通信；HyVGGT-VO [^45^] 同样将"计算密集型推理分离到独立异步线程，确保传统VO前端完全不被阻塞"。这种架构的延迟敏感型前端（定位）与计算密集型后端（决策）在物理上解耦，互不干扰。

### 2.1 与单循环架构的本质区别

| 维度 | 单循环（同步） | 双循环（异步） |
|------|-------------|--------------|
| SLAM频率 | 与决策同频（低） | **独立高频运行** |
| 决策频率 | 每步都决策 | **条件触发，低频** |
| 目标稳定性 | 频繁切换，路径抖动 | **目标持久，路径平滑** |
| 计算负载 | 每步都计算信息增益 | **仅触发时计算** |
| 定位连续性 | 受决策延迟影响 | **连续无中断** |
| 实现复杂度 | 简单 | 需要状态机协调 |

## 3. 触发条件设计（Trigger Conditions）

决策不是定时执行的，而是由**多维度触发条件**动态判断。参考 Zhang & Zhou [^55^] 的重规划策略（轨迹碰撞检测 + 固定间隔）和 Amazon Science [^52^] 的自适应阈值设计（"随上次ALC时间单调递减，使ALC激活更容易"），本文设计四类触发条件：

### 3.1 时间触发（Periodic Trigger）

最简单的触发方式：每执行 $N$ 个SLAM步强制触发一次决策。这确保即使其他条件长期不满足，系统也会定期重新评估态势。$N$ 的选取取决于环境动态性和传感器频率，通常设为 $N = 20 \sim 100$（即每1-5秒触发一次，假设传感器50Hz）。

```matlab
trigger.time_counter = trigger.time_counter + 1;
if trigger.time_counter >= trigger.N_period
    trigger.flag = true;
    trigger.time_counter = 0;
end
```

### 3.2 空间触发（Spatial Trigger）

当机器人**到达当前目标点附近**时触发重决策。这是最直接、最常用的触发条件。目标点可以是上一周期决策选定的前沿探索目标或回环闭合目标。距离阈值应略小于传感器有效范围，确保在到达前还能获取足够的新观测。

$$\text{trigger}_{\text{spatial}} = \| \hat{x}_{\text{current}} - x_{\text{target}} \|_2 < d_{\text{threshold}}$$

$d_{\text{threshold}}$ 通常取传感器量程的 $20\% \sim 40\%$，例如激光雷达10m量程时设为 $2 \sim 4$ m。

### 3.3 不确定性触发（Uncertainty Trigger）

当位姿估计的不确定性（协方差矩阵行列式或最大特征值）超过安全阈值时，说明当前轨迹可能导致定位漂移，需要重新规划以降低不确定性。参考 Zhang et al. [^57^] 的D-opt准则：当 $m_{D-opt} > \text{Th}_{D-opt}$ 时执行主动回环闭合。Amazon Science [^52^] 更进一步采用**自适应阈值**——随上次重规划时间单调递减，使触发更容易。

$$\text{trigger}_{\text{uncertainty}} = \det(\Sigma_t) > \text{Th}_{\Sigma} \cdot \alpha^{\Delta t_{\text{last}}}$$

其中 $\alpha \in (0,1)$ 是衰减系数，$\Delta t_{\text{last}}$ 是距离上次决策的时间步数。自适应阈值的思想是：**机器人运行越久不触发决策，阈值越低，越容易触发**，从而防止长期不触发导致不确定性失控。

### 3.4 事件触发（Event-based Trigger）

由特定事件驱动，主要包括：

**重采样退化事件**：当有效粒子数 $N_{\text{eff}} = 1/\sum w_i^2$ 低于临界值时，粒子滤波退化严重，说明当前轨迹或观测质量差，需要重新规划到信息更丰富的区域。

**新前沿发现事件**：当传感器发现大片未知区域的前沿边界时，可能值得调整目标。

**碰撞风险事件**：当前目标路径上检测到新障碍物（参考 Zhang & Zhou [^55^] 的"轨迹与新障碍物碰撞即触发重规划"）。

### 3.5 触发条件综合判断

```matlab
function should_replan = check_trigger_conditions(belief, state, trigger_params)
    % 综合判断是否需要重规划
    
    should_replan = false;
    
    % [1] 时间触发
    trigger_params.time_counter = trigger_params.time_counter + 1;
    if trigger_params.time_counter >= trigger_params.N_period
        should_replan = true;
        trigger_params.time_counter = 0;
        trigger_params.reason = 'time_periodic';
        return;
    end
    
    % [2] 空间触发：到达当前目标附近
    dist_to_goal = norm(belief.pose_mean(1:2) - state.current_goal(1:2));
    if dist_to_goal < trigger_params.spatial_threshold
        should_replan = true;
        trigger_params.reason = 'reached_goal';
        return;
    end
    
    % [3] 不确定性触发（自适应阈值）
    pose_uncertainty = det(belief.pose_cov);
    adaptive_threshold = trigger_params.sigma_threshold * ...
                         (trigger_params.alpha ^ trigger_params.time_counter);
    if pose_uncertainty > adaptive_threshold
        should_replan = true;
        trigger_params.reason = 'high_uncertainty';
        return;
    end
    
    % [4] 事件触发：粒子退化
    if belief.Neff < trigger_params.Neff_threshold
        should_replan = true;
        trigger_params.reason = 'particle_depletion';
        return;
    end
end
```

## 4. 状态机设计（State Machine）

状态机协调两个循环的运行逻辑，确保高频SLAM和低频决策不会冲突。

| 状态 | 含义 | 高频SLAM | 低频决策 |
|------|------|---------|---------|
| **INIT** | 初始化 | 运行 | 等待首帧数据后触发 |
| **EXECUTING** | 执行当前目标 | **持续运行** | 监控触发条件 |
| **REPLANNING** | 重规划中 | **持续运行** | 执行决策算法 |
| **LOOP_CLOSURE** | 主动回环闭合 | **持续运行** | 规划回环路径 |
| **TERMINATED** | 探索完成 | 停止 | 停止 |

```matlab
%% ===================================================================
%  状态机主控逻辑（在每个高频SLAM步调用）
%% ===================================================================

function state = state_machine_update(state, belief, trigger_params)
    switch state.mode
        case 'INIT'
            % 等待SLAM收敛后首次触发决策
            if trigger_params.time_counter > 10  % 至少运行10步SLAM
                state.mode = 'REPLANNING';
                state.need_decision = true;
            end
            
        case 'EXECUTING'
            % 高频SLAM持续运行，监控触发条件
            if check_trigger_conditions(belief, state, trigger_params)
                state.mode = 'REPLANNING';
                state.need_decision = true;
            end
            
        case 'REPLANNING'
            % 决策完成后返回执行态
            if ~state.need_decision  % 决策已完成
                state.mode = 'EXECUTING';
            end
            
        case 'LOOP_CLOSURE'
            % 回环闭合模式：执行完回环后返回正常探索
            if state.loop_closure_completed
                state.mode = 'REPLANNING';
                state.need_decision = true;
            end
            
        case 'TERMINATED'
            % 探索完成，不再触发决策
            ;
    end
end
```

## 5. 完整MATLAB主程序

```matlab
%% ===================================================================
%  Async Active SLAM with FastSLAM 2.0
%  异步双循环架构：
%    - 高频循环：FastSLAM 2.0 后端 (每个传感器tick运行)
%    - 低频循环：主动决策 (触发条件满足时才执行)
%% ===================================================================

function [trajectory, maps, entropy_history, state_log] = async_active_slam_fastslam2()
    %% -------------------- 参数初始化 --------------------
    T_max = 10000;              % 最大高频步数（防止无限运行）
    M = 100;                    % FastSLAM粒子数
    map_size = [50, 50];        % 栅格地图尺寸 [m]
    cell_size = 0.1;            % 栅格分辨率 [m]
    sensor_range = 10;          % 传感器最大量程 [m]
    fov = 2*pi;                 % 传感器视场角 [rad]
    dt_slam = 0.02;             % SLAM周期 (50Hz = 20ms)
    
    % 机器人初始位姿 [x, y, theta]
    x_true = [2.5; 2.5; 0];     % 真实位姿（仿真用）
    
    %% -------------------- 触发条件参数 --------------------
    trigger_params = struct();
    trigger_params.N_period = 50;           % 时间触发：每50步触发
    trigger_params.time_counter = 0;
    trigger_params.spatial_threshold = 3.0;  % 空间触发：距目标<3m
    trigger_params.sigma_threshold = 0.5;    % 不确定性阈值（协方差行列式）
    trigger_params.alpha = 0.995;            % 自适应阈值衰减系数
    trigger_params.Neff_threshold = M * 0.3; % 粒子退化阈值
    trigger_params.reason = '';              % 触发原因记录
    
    %% -------------------- 状态机初始化 --------------------
    state = struct();
    state.mode = 'INIT';                     % 初始状态
    state.need_decision = false;             % 是否需要决策
    state.current_goal = x_true;             % 当前目标点
    state.current_path = [];                 % 当前路径
    state.loop_closure_completed = false;
    state.exploration_complete = false;
    
    %% -------------------- FastSLAM 2.0 初始化 --------------------
    particles = init_particles(M, x_true, map_size, cell_size);
    
    %% -------------------- 存储历史 --------------------
    trajectory = zeros(3, T_max);
    maps = cell(1, floor(T_max/50));         % 每50步保存一次地图
    entropy_history = zeros(1, T_max);
    state_log = cell(1, T_max);
    map_idx = 1;
    
    %% ===================================================================
    %  T_max 高频主循环（FastSLAM 2.0 后端持续运行）
    %% ===================================================================
    for t = 1:T_max
        
        %% ==========================================================
        %  [高频循环] Step 1: FastSLAM 2.0 后端更新
        %  这一步每个tick都执行，不做决策，只做状态估计
        %% ==========================================================
        
        % 从仿真器/机器人获取高频传感器数据
        [x_true, z_t, odom] = robot_highfreq_step(x_true, state.current_goal, ...
                                                     sensor_range, fov, dt_slam);
        
        % 调用 FastSLAM 2.0 后端（独立循环，见第6节）
        particles = fastslam2_backend(particles, M, odom, z_t);
        
        % 提取信念状态
        belief = extract_belief(particles, M);
        
        % 存储结果
        trajectory(:, t) = x_true;
        entropy_history(t) = belief.current_entropy;
        state_log{t} = state.mode;
        
        % 定期保存地图（降低存储频率）
        if mod(t, 50) == 0
            maps{map_idx} = belief.map;
            map_idx = map_idx + 1;
        end
        
        %% ==========================================================
        %  [低频决策循环入口] Step 2: 状态机更新 + 触发条件检查
        %  这一步根据状态机和触发条件决定是否执行决策
        %% ==========================================================
        
        % 状态机更新
        state = state_machine_update(state, belief, trigger_params);
        
        % 仅在需要决策时执行主动规划（低频）
        if state.need_decision
            
            fprintf('[%d] Decision triggered! Reason: %s | Pose uncertainty: %.4f\n', ...
                    t, trigger_params.reason, det(belief.pose_cov));
            
            %% ======================================================
            %  [低频循环] 主动决策模块
            %% ======================================================
            
            % 根据当前模式选择决策策略
            switch state.mode
                case 'REPLANNING'
                    % 正常探索：选择信息增益最大的前沿目标
                    [new_goal, path] = active_exploration_decision(...
                        belief, particles, M, sensor_range, fov);
                    
                case 'LOOP_CLOSURE'
                    % 回环闭合模式：选择最佳回环目标
                    [new_goal, path] = active_loop_closure_decision(...
                        belief, trajectory(:, 1:t));
                    state.loop_closure_completed = false;
            end
            
            % 更新状态
            state.current_goal = new_goal;
            state.current_path = path;
            state.need_decision = false;     % 决策完成
            state.mode = 'EXECUTING';         % 返回执行态
            
            % 重置触发计数器
            trigger_params.time_counter = 0;
        end
        
        %% ==========================================================
        %  Step 3: 检查终止条件
        %% ==========================================================
        if check_termination(belief, t, T_max)
            state.mode = 'TERMINATED';
            trajectory = trajectory(:, 1:t);
            entropy_history = entropy_history(1:t);
            fprintf('Exploration completed at step %d\n', t);
            break;
        end
        
        %% ==========================================================
        %  Step 4: 可视化
        %% ==========================================================
        if mod(t, 100) == 0
            visualize_async_slam(belief, trajectory(:, 1:t), ...
                                  state.current_goal, state.mode);
        end
    end
end
```

## 6. FastSLAM 2.0 高频后端（独立函数）

```matlab
%% ===================================================================
%  FastSLAM 2.0 后端：高频独立循环
%  输入：particles(上一时刻), odom(里程计增量), z_t(观测)
%  输出：particles(更新后)
%% ===================================================================

function particles = fastslam2_backend(particles, M, odom, z_t)
    % 此函数在每个高频tick被调用，只负责状态估计，不做决策
    
    new_particles = struct('pose', {}, 'landmarks', {}, 'weight', {});
    
    for m = 1:M
        %% [1] 运动预测
        s_pred = motion_model_odometry(particles(m).pose, odom);
        
        %% [2] 数据关联
        [associations, ~] = data_association(s_pred, particles(m).landmarks, z_t);
        
        %% [3] FastSLAM 2.0 提议分布（融合观测）
        if ~isempty(associations) && any(associations > 0)
            [mu_proposal, Sigma_proposal] = compute_proposal_distribution(...
                s_pred, particles(m).landmarks, z_t, associations);
            s_t = mvnrnd(mu_proposal, Sigma_proposal)';
        else
            % 无有效观测：回退到运动模型
            Q = diag([0.05, 0.05, 0.02]);
            s_t = mvnrnd(s_pred, Q)';
        end
        
        %% [4] 地标更新
        updated_landmarks = particles(m).landmarks;
        for i = 1:length(associations)
            if associations(i) == 0
                % 初始化新地标
                new_lm = init_landmark(s_t, z_t(:, i));
                updated_landmarks = [updated_landmarks, new_lm];
            elseif associations(i) > 0
                % EKF更新已知地标
                updated_landmarks(associations(i)) = ekf_update_landmark(...
                    s_t, updated_landmarks(associations(i)), z_t(:, i));
            end
        end
        
        %% [5] 权重计算
        w = compute_importance_weight(s_t, s_pred, particles(m).landmarks, z_t, associations);
        
        new_particles(m) = struct('pose', s_t, ...
                                   'landmarks', {updated_landmarks}, ...
                                   'weight', w);
    end
    
    %% [6] 归一化权重
    weights = [new_particles.weight];
    weights = weights / sum(weights);
    for m = 1:M, new_particles(m).weight = weights(m); end
    
    %% [7] 重采样
    Neff = 1 / sum(weights.^2);
    if Neff < M * 0.5
        particles = resample_particles(new_particles, M);
    else
        particles = new_particles;
    end
end
```

## 7. 主动决策模块（低频触发时执行）

```matlab
%% ===================================================================
%  主动探索决策：仅在触发条件满足时执行
%% ===================================================================

function [best_goal, path] = active_exploration_decision(...
    belief, particles, M, sensor_range, fov)
    
    % [Step 1] 提取前沿候选目标
    frontier_goals = extract_frontiers(belief.map, belief.pose_mean(1:2), sensor_range);
    
    if isempty(frontier_goals)
        % 无可探索前沿，任务完成
        best_goal = belief.pose_mean;
        path = [];
        return;
    end
    
    % [Step 2] 对每个候选目标计算信息增益
    n_goals = size(frontier_goals, 2);
    info_gains = zeros(1, n_goals);
    path_costs = zeros(1, n_goals);
    
    for g = 1:n_goals
        goal = frontier_goals(:, g);
        
        % 模拟到达该目标后的观测
        simulated_obs = simulate_observation_at_goal(...
            goal, belief.map, sensor_range, fov);
        
        % 预测信息增益（联合熵的降低）
        predicted_entropy = predict_entropy_after_observation(...
            belief, goal, simulated_obs);
        
        info_gains(g) = belief.current_entropy - predicted_entropy;
        
        % 路径代价（距离）
        path_costs(g) = norm(goal(1:2) - belief.pose_mean(1:2));
    end
    
    % [Step 3] 综合评分 = 信息增益 - lambda * 路径代价
    lambda = 0.1;  % 权衡系数
    scores = info_gains - lambda * path_costs;
    
    % [Step 4] 选择最优目标
    [~, best_idx] = max(scores);
    best_goal = frontier_goals(:, best_idx);
    
    % [Step 5] 生成到目标的路径（A*或其他路径规划器）
    path = plan_path(belief.pose_mean, best_goal, belief.map);
end
```

```matlab
%% ===================================================================
%  主动回环闭合决策：当不确定性超过阈值时触发
%% ===================================================================

function [loop_goal, path] = active_loop_closure_decision(belief, trajectory_history)
    % 从历史轨迹中选择最佳回环目标
    % 目标：最大化回环后位姿不确定性的降低
    
    current_pose = belief.pose_mean;
    n_history = size(trajectory_history, 2);
    
    % 候选回环点：历史轨迹中距离当前位置足够远且足够老的点
    loop_candidates = [];
    for i = 1:50:n_history-100  % 每50步采样一个候选
        hist_pose = trajectory_history(:, i);
        dist = norm(hist_pose(1:2) - current_pose(1:2));
        
        % 回环点应距离当前位置适中（不太近也不太远）
        if dist > 5 && dist < 20
            loop_candidates = [loop_candidates, hist_pose];
        end
    end
    
    if isempty(loop_candidates)
        % 无可回环点，返回当前位置附近
        loop_goal = current_pose;
        path = [];
        return;
    end
    
    % 选择距离最近且不确定性降低最大的点
    [~, best_idx] = min(vecnorm(loop_candidates(1:2, :) - current_pose(1:2)));
    loop_goal = loop_candidates(:, best_idx);
    
    % 规划回环路径
    path = plan_path(current_pose, loop_goal, belief.map);
end
```

## 9. 高频执行层的简化控制

高频循环中，机器人需要持续向当前目标点移动，但不需要每一步都做全局决策。采用简单的**跟踪控制器**：

```matlab
%% ===================================================================
%  高频机器人步进：跟踪当前目标（纯追踪或PID）
%% ===================================================================

function [x_new, z_t, odom] = robot_highfreq_step(x_current, current_goal, ...
                                                     sensor_range, fov, dt)
    % 计算到目标的方位
    dx = current_goal(1) - x_current(1);
    dy = current_goal(2) - x_current(2);
    target_heading = atan2(dy, dx);
    
    % 航向误差
    heading_error = wrapToPi(target_heading - x_current(3));
    
    % 距离目标
    dist_to_goal = sqrt(dx^2 + dy^2);
    
    % 纯追踪控制器生成速度指令
    v_max = 1.0;        % 最大线速度 [m/s]
    omega_max = 0.5;    % 最大角速度 [rad/s]
    
    % 线速度：距离远时全速，接近时减速
    v_cmd = min(v_max, dist_to_goal * 0.5);
    
    % 角速度：与航向误差成正比
    omega_cmd = max(-omega_max, min(omega_max, heading_error * 2.0));
    
    % 如果很接近目标，停止
    if dist_to_goal < 0.5
        v_cmd = 0;
        omega_cmd = 0;
    end
    
    % 执行运动（加入噪声模拟真实机器人）
    [x_new, odom] = execute_motion(x_current, v_cmd, omega_cmd, dt);
    
    % 获取传感器观测
    z_t = get_sensor_observation(x_new, sensor_range, fov);
end
```

## 10. 触发条件的数学分析与调参建议

### 10.1 各触发条件的触发频率

| 触发类型 | 典型频率 | 适用场景 | 调参建议 |
|---------|---------|---------|---------|
| 时间触发 | 每1-5秒 | 确保定期重评估 | $N_{period} = f_{sensor} \times T_{interval}$ |
| 空间触发 | 每到达一个目标 | 探索型任务 | $d_{threshold} = (0.2 \sim 0.4) \times r_{sensor}$ |
| 不确定性触发 | 不确定性增长时 | 定位漂移风险高时 | $\text{Th}_\Sigma$ 取历史均值的5-8倍 [^57^] |
| 事件触发 | 偶发 | 应对突发情况 | $N_{eff} < 0.3M$ 时触发 |

### 10.2 触发条件的优先级

当多个触发条件同时满足时，按以下优先级处理：

1. **最高**：事件触发（粒子退化、碰撞风险）—— 必须立即响应
2. **高**：不确定性触发 —— 定位安全相关
3. **中**：空间触发 —— 正常探索流程
4. **低**：时间触发 —— 兜底机制
